# Security

Please report a vulnerability privately to alfonso@vexilo.com, or through
[GitHub's private vulnerability reporting](https://github.com/alfonsobries/sanctumrosarium/security/advisories/new),
not in a public issue.

Include what is affected (iOS, Android, Apple Watch or the website), the version and
the steps to reproduce it. You will get an answer within a few days.

The apps have no server and no accounts: the journal and settings stay on the device,
and the watch syncs with the phone over WatchConnectivity.
